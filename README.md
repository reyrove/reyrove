## 🌿 The Practice

I started with **fibers**. Then I started asking what happens when fibers become **algorithms**. 

My work moves between textile engineering, mathematics, creative coding, generative art, and AI. I am interested in the hidden structures behind things: rhythm, repetition, tension, geometry, texture, and systems. 

Code becomes a kind of loom — a way to turn rules into forms, materials into experiences, and experiments into visual language.

## 💻 The Codebase

This repository holds the source code for my personal portfolio. It is a fully static, single-page site built from scratch without heavy frameworks.

*   **Architecture:** Vanilla HTML5, CSS3, and JavaScript (ES5-compatible).
*   **Design System:** Custom CSS properties, fluid typography (`clamp()`), and grid/flexbox layouts. Dark, gold-on-charcoal palette.
*   **Data-Driven:** Projects are rendered dynamically from a single `PROJECTS` array in `script.js`, keeping the UI, filters, and JSON-LD SEO data perfectly in sync.
*   **Accessibility:** Full `prefers-reduced-motion` support, screen-reader friendly filters, skip links, and keyboard-navigable mobile menus.
