### 001 / THE PERSON BEHIND THE PATTERN

I'm **Reyhaneh Daneshdoost**, known as **Reyrove**.

I studied how fibers behave. Then I started teaching algorithms how to create.

Now I work somewhere between textile engineering, generative art, creative coding, AI experiments, and scientific computing.

I see code as a material. Mathematics as a design language. Algorithms as looms capable of weaving things that don't exist yet.

I build visual systems, interactive tools, computational patterns, and experiments that blur the boundary between engineering and art.

**I don't just write code. I use it to build visual languages.**

### 008 / THE PHILOSOPHY

> The same curiosity that made me study how threads twist is now making me study how systems think.

I believe engineering can be expressive, mathematics can be intuitive, and technology can be beautiful without sacrificing precision.

I'm not interested in eliminating chaos.

**I'm interested in discovering its hidden structure.**
